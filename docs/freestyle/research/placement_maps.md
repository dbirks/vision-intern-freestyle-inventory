# Public Freestyle placement maps

Transcribed 2026-11-26 from the rendered pages in `data/reference/web/pdf_pages/`. These are examples of regional, model-specific lineups, not a universal planogram. A map cell or logo is not automatically a single removable cartridge or tray. Blank means the chart shows an empty grey/white position; it does not prove an unused physical pump. P1/P2 below is included only where printed.

## Trays and orientation

[Cartridge Management](https://crewconnect.coca-cola.com/wp-content/uploads/2019/05/CCFS-CartridgeManagement-Quick-Tip-1.pdf), local `pdf_pages/cartridge-management/page-01.png`, says single cartridges always use single trays, says double cartridges are glued together, and illustrates single and double trays and doors. It recommends sliding a tray over an upside-down cartridge for fitting; this is a staging technique, not proof the installed cartridge is upside down. It does not label left/right P1/P2 on an installed glued double. The [9000 guide](https://crewconnect.coca-cola.com/wp-content/uploads/2019/05/Coca-Cola_9000-User-Guide-2.pdf), local rendered pages, identifies the RFID stripe along the top for scanning; it does not specify which part is left or right. The older [dispenser guide](https://device.report/m/63efb5a702a7653f3749d28489520265e1055bf3d67abed49942d3b4ccb545e1.pdf) separately instructs that the side label face up when loaded. Therefore the visual arrangements above are map order only, not a confirmed physical P1/P2 orientation for double trays. Inspect model-specific installation instructions or a clear labeled installed pair before relying on one.
